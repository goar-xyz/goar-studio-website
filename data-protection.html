Data Protection & Local Privacy

How Goar Studio stores, encrypts, routes, backs up, and deletes your data on Android.

Goar Studio — Data Protection & Local Privacy Overview 1. Local-First Storage Architecture Goar Studio stores your conversations, system prompts, agent memories, tasks, notes, calendar events, and browser data locally on your device using Android Room (SQLite) and Jetpack DataStore. 2. Credential Protection Provider API keys, gateway credentials, and SSH secrets are encrypted on device using Android Keystore-backed EncryptedSharedPreferences. 3. Network Connections Outbound requests are sent directly from your device only to the AI model providers, MCP servers, web search engines, SSH hosts, or API endpoints that you configure and enable. Goar Studio does not bundle third-party advertising SDKs or hidden analytics trackers in this build. 4. Your Data Controls From Settings → Data Control, you can export encrypted-optional backups (ZIP), import conversation archives, configure automatic local backups, or delete stored histories and keys at any time.

Summary of Technical Safeguards

Database Layer

App-private Android Room SQLite database with local WAL persistence for chats, branches, tool outputs, tasks, and semantic RAG embeddings.

Secrets & SSH Pinning

API keys, payment card profiles, and SSH keys reside in Android Keystore-encrypted preferences. Remote SSH servers require explicit host-key fingerprint verification and per-command approval unless explicitly trusted.

Browser Shielding

The integrated Browser ships with bundled domain blocklists (hosts.txt and malware.txt), full cookie clearing/export, live network inspection, and Cloak stealth controls.

Portability & Right to Erasure

Import existing Claude or ChatGPT archives, export full ZIP backups to your chosen storage folder, configure auto-delete retention windows, or clear the entire local database in one step.
