Goar Studio — Data Protection & Local Privacy Overview 1. Local-First Storage Architecture Goar Studio stores your conversations, system prompts, agent memories, tasks, notes, calendar events, and browser data locally on your device using Android Room (SQLite) and Jetpack DataStore. 2. Credential Protection Provider API keys, gateway credentials, and SSH secrets are encrypted on device using Android Keystore-backed EncryptedSharedPreferences. 3. Network Connections Outbound requests are sent directly from your device only to the AI model providers, MCP servers, web search engines, SSH hosts, or API endpoints that you configure and enable. Goar Studio does not bundle third-party advertising SDKs or hidden analytics trackers in this build. 4. Your Data Controls From Settings → Data Control, you can export encrypted-optional backups (ZIP), import conversation archives, configure automatic local backups, or delete stored histories and keys at any time.

1. Hardware-Backed Secret Storage (Android Keystore AES-256-GCM)

Every user-supplied API key, OAuth 2.1 PKCE bearer/refresh token, Google Identity Services token, SSH key, and vaulted card profile is encrypted locally using AES-256-GCM with non-exportable master keys generated inside the Android hardware-backed Keystore (TEE / StrongBox when available). Secrets are never written in plaintext to external storage or cloud backups (android:allowBackup="false").

2. Network Isolation, OAuth 2.1 & SSRF / DNS-Rebinding Protection

  • TLS 1.2 / 1.3 Enforcement: Outbound connector calls use OkHttp and Ktor with strict TLS certificate validation.
  • Device-Native OAuth: Optional Google Drive authorization uses Android's official Google Identity Services AuthorizationClient; OAuth 2.1 PKCE connectors resolve directly via goar://oauth/callback or loopback with zero intermediary proxy.
  • SSRF & Private-Range Guard: Autonomous HTTP/OpenAPI/MCP tool calls validate resolved IPv4/IPv6 addresses to block untrusted prompts from probing link-local metadata endpoints (169.254.169.254) or unauthorized loopback interfaces unless explicitly targeting user-configured local inference servers.
  • Zero Dynamic Code Loading (DCL): Goar Studio never downloads external .dex, .jar, rootfs tarballs, or untrusted .so binaries at runtime. The bundled Alpine Linux 3.21 minirootfs is embedded inside the signed APK and SHA-256 verified before extraction.

3. SmartCookieWeb Per-Origin Privacy Shield

  • Ad & Tracker Host Blocking: Bundled domain blocklists (hosts.txt & malware.txt) block known ad-tech and malware hosts with per-site allowlist controls.
  • HTTPS-Only & Global Privacy Control: Automatic HTTPS upgrade plus DNT: 1 and Sec-GPC: 1 request headers and DOM signals.
  • Per-Host JavaScript Gate & Incognito Isolation: Toggle JavaScript per domain in one tap; closing Incognito tabs purges session cookies and leaves zero history footprint.

4. Bytecode Hardening, 16 KB NDK Binaries & AppIntegrityShield

Release builds compile through R8 whole-program shrinking, dictionary identifier obfuscation, resource shrinking, debug log stripping, and 16 KB page-aligned stripped C/C++ shared libraries across all 14 arm64-v8a and x86_64 JNI binaries (libgoar_llama.so, libgoar_whisper.so, libproot_exec.so, atomic file JNI). At startup, AppIntegrityShield verifies X.509 APK signing certificates and runtime hook integrity.

5. Instant Data & Credential Deletion Guide (Google Play User Data Policy)

Zero Cloud Account Required: Because 100% of your workspace lives locally on your device, you can delete individual records or wipe everything instantaneously without waiting on support approval.
  1. Granular In-App Deletion (Keep App Installed): Long-press any thread in the Drawer to delete chats; clear API keys or OAuth tokens in Settings → API Hub & OAuth 2.1; clear site storage inside SmartCookieWeb's Shield menu; or delete apps in App Screen.
  2. Complete Instantaneous Wipe via Android OS: Open system Settings → Apps → Goar Studio → Storage & cache → Clear storage (or uninstall). Android immediately and irreversibly destroys all local Room SQLite databases, Alpine sandbox files, cached media, and hardware-backed Android Keystore keys.
  3. Revoke Optional Google Drive OAuth Grant: Disconnect inside Goar Studio or revoke immediately at myaccount.google.com/permissions.
  4. Delete Optional Support Messages: Email goarcontact@m.kuku.lu with subject Delete Support Record to permanently purge any past support correspondence within 7 business days.

6. Coordinated Vulnerability Disclosure

Security researchers discovering a potential issue are invited to report it responsibly via the in-app Support Desk or email goarcontact@m.kuku.lu (RFC 9116 disclosure active; initial triage within 72 hours).
