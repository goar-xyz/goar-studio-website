# Goar Studio — Official Companion Website & 1:1 Interactive Simulator

Static companion website for **Goar Studio v2.0.0 (Build 30)** featuring:

- Editorial product showcase with 5 live choreographed interactive Android phone video reels (`Ask`, `Build`, `Imagine`, `SOUL.md Agents & Live Voice`, and `Linux PRoot / Workspaces`)
- Full 14-screen hands-on 1-to-1 interactive simulator (`simulator.html`)
- Verbatim legal & compliance pages (`privacy.html`, `terms.html`, `data-protection.html`, `licenses.html`)
- Ink Dark (`#000000` / `#E8E2D6`) and Paper Light (`#EFE9DF` / `#000000`) theme sync
- Zero build step, zero external CDN dependencies — ready for instant GitHub Pages deployment via `.github/workflows/deploy-pages.yml`.

## Local Preview

```bash
python -m http.server 8787
```

Open `http://127.0.0.1:8787/index.html` or `http://127.0.0.1:8787/simulator.html`.
