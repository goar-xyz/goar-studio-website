# Goar Studio — Official Companion Website & 1:1 Interactive Simulator

Static companion website for **Goar Studio v2.1.0 (Build 31)** featuring:

- Architectural Monochrome design system: Obsidian Dark (`#060608` / `#F4F4F6`) & Crisp Alabaster Light (`#FAFAFB` / `#0B0B0E`) with live 4-palette `GoarPaletteStyle` switcher (`MONOCHROME`, `CHAMPAGNE`, `COBALT`, `TINTED`) and the geometric monochrome G brand mark
- Editorial product showcase with 5 live choreographed interactive Android phone video reels (`Ask`, `Build`, `Imagine`, `SOUL.md Agents & Live Voice`, and `Linux PRoot / Revise / Network Tools / Tiered Settings`)
- Full 16-screen hands-on 1-to-1 interactive simulator (`simulator.html`) including `MainTopTabSegmentedPill`, inline composer Agents button, 4-tab Network Tools (Target Lookup, LAN Scan, Live Traffic, Shadow Trap), OAuth 2.1 PKCE Hub, 16 bundled skills (incl. 3 NVIDIA AI playbooks), and `/drop` commerce command
- Verbatim legal & compliance pages (`privacy.html`, `terms.html`, `data-protection.html`, `licenses.html`)
- Zero build step, zero external CDN dependencies — ready for instant GitHub Pages deployment via `.github/workflows/deploy-pages.yml`.
