Privacy Policy

Effective Date: November 2026 · Applies to Goar Studio v2.1.0 for Android (com.aistudio.goarstudio.kxrqvn) & goarxyz.com

Goar Studio Privacy Policy Goar Studio stores conversations, workspace files, task schedules, and provider API keys locally on your device using Android Room and EncryptedSharedPreferences. Network Requests: Network traffic is sent only to the model providers, search backends, MCP servers, or endpoints that you explicitly configure and invoke. Telemetry: Diagnostic logging remains local unless you explicitly export a diagnostic bundle.

1. Local-First Data Storage

Goar Studio is architected as a local-first Android workspace. Your conversations, system prompts, agent SOUL.md profiles, saved memories, workspace files, built web apps, scheduled tasks, notes, calendar events, and browser history are stored locally on your device using Android Room (SQLite) and Jetpack DataStore. Goar Studio does not operate a centralized user-data cloud database that scrapes or stores your private prompts.

2. Hardware-Backed Credential & OAuth 2.1 PKCE Security

API keys for AI model providers, OAuth 2.1 PKCE access and refresh tokens (completed locally via goar://oauth/callback, loopback redirect, or Google Identity Services), search APIs, MCP bearer tokens, IMAP/SMTP mail credentials, SSH private keys, and vaulted card profiles are stored locally inside Android Keystore-backed EncryptedSharedPreferences. You can further restrict app access using App Lock PIN and biometric authentication in Settings → Security & App Lock.

3. Outbound Network Requests & Third-Party Endpoints

Network connections are initiated directly from your device exclusively to third-party services that you explicitly configure, authorize via OAuth 2.1, or navigate to — including AI model providers (such as Anthropic, OpenAI, Google Gemini, NVIDIA NIM, DeepSeek, Mistral, Groq, OpenRouter, xAI, Pollinations, or custom/local Ollama servers), web search engines, MCP servers (such as GitHub, Vercel, Supabase, Cloudflare, Notion, Linear, Stripe, Figma, or Google Drive/Gmail/Calendar), SSH servers, or URLs opened inside the built-in Browser. Your interactions with those third-party endpoints are governed by the respective provider's privacy policy.

4. Local On-Device Models & Offline Execution

When using local GGUF language models via embedded llama.cpp, local speech recognition via whisper.cpp, the On-Device Creative Engine, local PRoot Linux containers, or local workspace editing, inference and file processing run strictly on-device without transmitting prompt contents over the network.

5. Telemetry, Integrity & Zero Ad Trackers

Goar Studio does not bundle third-party advertising SDKs or hidden cross-app ad trackers. Diagnostic HTTP traces and logs remain local on your device unless you explicitly choose to export a diagnostic bundle or submit a support inquiry via the Contact Admin Desk. Local App Integrity Shield verification and optional Firebase analytics controls can be reviewed in Settings → About & Legal.

6. Your Rights: Export, Backup & Deletion

  • Export & Backup: Export your conversations and settings as local ZIP archives or schedule automatic local backups from Settings → Data & Backups. Note that exported plaintext backups containing API keys should be stored securely.
  • Auto-Delete & Erasure: Configure automatic chat retention periods (1 week, 1 month, or 1 year) or permanently wipe conversations, OAuth tokens, browser cookies, workspace files, and API keys at any time directly on your device.
  • Live Auditability: Inspect live HTTP requests, WebView network traffic, LAN telemetry, and TLS sessions directly inside Network Tools (accessible from the main drawer and Settings).

7. Contact

For privacy inquiries, security disclosures, or data protection questions, contact developer support at admin@goarxyz.com.
