Core Privacy Guarantee: Goar Studio is architected as a local-first, Bring-Your-Own-Key (BYOK) workstation. Your conversations, workspaces, SmartCookieWeb browsing history, custom SKILL.md playbooks, API keys, Google OAuth tokens, and MCP credentials remain stored locally on your Android device and are never sold, rented, or monetized for advertising.
Goar Studio Privacy Policy Goar Studio stores conversations, workspace files, task schedules, and provider API keys locally on your device using Android Room and EncryptedSharedPreferences. Network Requests: Network traffic is sent only to the model providers, search backends, MCP servers, or endpoints that you explicitly configure and invoke. Telemetry: Diagnostic logging remains local unless you explicitly export a diagnostic bundle.

1. Summary of Data Collection & Local Storage

Goar Studio does not require a Goar cloud account. All primary records live strictly inside Android's sandboxed app-private storage (context.filesDir, Android Room SQLite, and Jetpack DataStore) with android:allowBackup="false":

  • API Keys, OAuth 2.1 PKCE Tokens & MCP Credentials: Encrypted at rest using 256-bit AES-GCM keys backed by hardware Android Keystore (TEE / StrongBox when available). Requests connect directly over TLS 1.2/1.3 from your device to endpoints you explicitly configure (Anthropic, OpenAI, Google Gemini, NVIDIA NIM, xAI, DeepSeek, Cloudflare, GitHub, Vercel, Supabase, Stripe, Google Drive, or local Ollama/LM Studio).
  • Conversations, Skills, Web Apps & 3D Games: Stored locally on your device. You may export or erase them at any time.
  • SmartCookieWeb Browser Data: Tabs, bookmarks, cookies, and offline .mht archives live exclusively on-device. Incognito tabs never write to history and purge session cookies upon tab closure.
  • Zero Advertising Identifier (AD_ID): Goar Studio explicitly strips com.google.android.gms.permission.AD_ID and Android AdServices permissions in AndroidManifest.xml.

3. Google API Services User Data Policy (Limited Use Disclosure)

Google Workspace & Google Drive Limited Use Commitment: Goar Studio's use and transfer to any other app of information received from Google APIs (including the optional https://www.googleapis.com/auth/drive scope) adheres strictly to the Google API Services User Data Policy, including the Limited Use requirements.
  • Google Drive access is requested only when you explicitly tap Connect Google Drive in Build or API Hub.
  • OAuth access tokens stay locally on your device, are never transmitted to Goar servers, are never used for serving advertisements, and are never used to train generalized AI/ML models.
  • Revoke Goar Studio's Google Drive access at any time via Google Account Permissions.

4. Android Permissions & Scoped Storage Minimization

  • No Broad Storage Permissions: Goar Studio does not request MANAGE_EXTERNAL_STORAGE, READ_MEDIA_IMAGES, or READ_MEDIA_VIDEO. Media attachments use the zero-permission Android Photo Picker (PickVisualMedia) and Storage Access Framework (OpenDocument).
  • System Files Integration: Workspace and offline Alpine Linux 3.21 sandbox files are exposed safely via Android's standard DocumentsProvider.
  • Camera & Microphone: Optional runtime permissions requested strictly when initiating visual capture or live voice input.
  • Notifications & Foreground Data Sync: Used to keep user-scheduled autonomous tasks and local builds alive reliably with a visible status notification.

5. Local On-Device Execution & Third-Party BYOK Endpoints

When using local GGUF models via libgoar_llama.so, local voice recognition via libgoar_whisper.so, the On-Device Creative Engine, or the APK-bundled SHA-256 verified Alpine Linux 3.21 PRoot environment, processing runs strictly on-device with zero outbound network transmission. When you configure external providers or OAuth connectors, outbound calls are governed by each third-party provider's privacy policy.

6. Your Rights (GDPR, UK GDPR, CCPA/CPRA) & Instant Deletion

Because your data lives locally on your device, you have immediate unilateral control to inspect, export encrypted-optional ZIP archives, revoke OAuth grants, or permanently wipe all records without waiting on a third party. See our full 4-option Security & Data Deletion Guide.
